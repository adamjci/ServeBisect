# Regression cases

ServeBisect case studies are small, public, rerunnable reproductions of upstream inference regressions. Each case records the upstream source, exact good/bad revisions where known, hardware assumptions, a benchmark contract, and the expected classification.

The first case is [`vllm-49013`](vllm-49013/README.md), derived from vLLM issue #49013. It microbenchmarks the structured-output staging hot path that upstream maintainers identified as the cause of a roughly 2x decode-throughput regression. The checked-in benchmark deliberately avoids model downloads so the root-cause signal can be verified quickly before spending more GPU time on a full end-to-end reproduction.

Case artifacts generated by a GPU run belong under the case's `artifacts/` directory and should be reviewed for sensitive information before publication.
